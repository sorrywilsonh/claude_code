# 程式撰寫規範

依現有程式碼(`systems/order-record-converter/src/convert.cpp`)歸納,新程式與修改一律遵循:

- **錯誤處理**:遇到不可恢復的錯誤,印出訊息到 stderr 並用明確的 exit code 中止(例如資料異常用 `exit(2)`、I/O 失敗用 `exit(1)`),不要吞掉錯誤或靜默略過
- **平台差異**:用前置處理器區分(如 `#if defined(_GUARDIAN_TARGET) ...`),上層邏輯保持平台無關,只有 I/O wrapper 分平台實作
- **硬性限制要寫清楚來源**:像 buffer 上限這類數字,註解要說明限制從哪來、怎麼算出來的,不要只寫死一個數字
- **編譯期能檢查就不留到執行期**:結構大小等假設用編譯期斷言卡住(例如 `typedef char assert_x_[sizeof(T) == N ? 1 : -1]`)
- **檔案開頭要有說明註解**:這支程式做什麼、設計重點、怎麼編譯、怎麼執行
